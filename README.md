## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/kanchan9675/KanchanTomar_Cerso_WebDev_Internship.git
```

2. Navigate to the project folder:

```bash
cd KanchanTomar_Cerso_WebDev_Internship
```

3. Open `index.html` in your browser, or use a local development server.
